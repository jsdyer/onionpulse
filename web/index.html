Why the estimate spiked in late October 2026

After an October 28 directory change, older Tor clients repeatedly requested network information. Tor uses request counts to estimate clients, so the retries inflated the estimates across countries. Tor released a mitigation on November 4. The shaded dates show the rise and return in the Canadian series.

How to read the data

Tor estimates clients from aggregate directory requests. These series show national and worldwide activity. The counts can change with measurement coverage, routing, or client behaviour. Country and territory labels follow geographic codes supplied by Tor Metrics.

The charts show daily values beginning in 2021. Gaps indicate days without a reported value. Recent days can be revised as data arrives. The dates are in UTC.
